01

执行钱包

读取中
自动买入使用的钱包地址 等待本地服务

实盘需要执行钱包。本地服务会使用这个钱包签名。

导入或更换钱包＋
  1. 在本项目文件夹中打开终端

    先进入含有 package.json 的项目目录，再运行下面的命令。 

    npm run wallet:import
  2. 按照终端提示粘贴钱包私钥

    输入内容会隐藏。导入完成只显示公开的钱包地址，核对它是否属于你要使用的钱包。

  3. 回到这里，点击「重新加载钱包」

    先停止监听再更换钱包。地址加载成功后，再检查实盘就绪状态。

⌑

私钥保存在本机项目的 .env 文件中，文件权限仅限当前用户读写，但内容是明文、未加密。不要把私钥发到聊天或粘贴到网页，也不要分享这个文件。
